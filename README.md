# Tulips 🌷

A ray-traced tulip garden that grows and blooms around Amy's name — a single,
self-contained web page (real-time raymarched WebGL, embedded fonts, no external
requests).

## Deploy with GitHub Pages

1. **Settings → Pages → Build and deployment**
2. Source: **Deploy from a branch**
3. Branch: **main**, folder **/ (root)** → Save

A minute or two later the garden is live at:

**https://jrigholman.github.io/tulips/**

## Personalize

Open `index.html` and search for `✏️` — the message lines are plain HTML text.
The name appears in `#name`, the intro card, and the fallback section.
